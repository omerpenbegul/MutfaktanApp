
# 🍽️ Mutfaktan - Recipe

This project is a recipe app developed using Swift and UIKit. Users can add, list, delete dishes and use the app individually. Data is managed via Firebase Firestore. Images are only kept locally on the device (Firebase Storage is not used).

---

## 🚀 Features

- 🔐 User login and registration with Firebase Authentication
- 📄 Firestore üzerinden yemek verilerinin saklanması
- ➕ Storing meal data via Firestore
- 🧾 Food listing (TableView)
- 🗑️ Delete food
- ✅ Made sign (isMade)
- 🖼️ Native image selection (UIImagePickerController)
- 🧠 MVVM architecture
- 🧩 Using UIKit + Storyboard
